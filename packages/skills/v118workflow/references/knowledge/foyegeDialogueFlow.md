### 一、核心：不是写满情绪，而是编排交流

人物对白不应只是 A 完整说完、B 准时开口。
每句话准确、每种情绪清楚、节奏过于整齐，仍可能像两个人排队朗读。
作者把方法称为「对白暗流编排」：设计人物**怎样尝试表达、怎样被情绪阻住、怎样被对方改变**。

停顿、口吃、改口和抢话不是随机装饰。
**先有心理原因，再有语言和身体上的变化。**
不是所有对白都需要失序，更不是越乱越真实。

### 二、设计话轮，而不是排列台词（约 01:26–01:56）

先确定：现在谁拥有话语权？谁准备接话？谁突然抢入？最后谁退让？
接话可以是**试探进入、插不进去、压过对方、主动退让**，而不只有「轮到我了」。

教程案例的具体参数：
- 男人最后一个词尚未结束、嘴还保持那个词的口型时，女人提前约 0.1 秒进入；
- 两人声音重叠约 0.2 秒；
- 男人不能因女人进入而突然静音；
- 女人先保持较低音量。

以上是**该案例的表演参数，不是所有对白必须执行的时间配额**。

### 三、何时抢话，何时沉默（约 01:56–02:28）

**抢话 = 不能让对方这句话继续。**
女人说到 “You can’t just die—”，男人立即连续否认 “I’m not.”。触发来自对方的**具体词**，而不是为了增加声音重叠。

女人说 “I don’t want to torture you.”，男人回答 “You’re not torturing me.”。他此前说不完整，此时却恢复较完整的表达——不是痛苦消失，而是眼前目标变成**先减轻女人的罪恶感**。

**沉默 = 还不知道怎样接住这句话。**
人物刚听到一个需要消化的秘密，就不应机械抢话。
所有地方都抢，只会把悲伤演成菜市场。

### 四、按心理障碍选择言语不流畅（约 02:28–03:21）

画面标注的专业概念是 **Speech disfluency（言语不流畅）**。它不是人物一紧张就随机结巴，而是**语言和情绪争夺同一个出口**。

先问：**人物此刻做不到什么？**

| 心理原因或障碍 | 语言怎样失败 |
|---|---|
| 羞耻、内疚、不敢承认自己，无法开始 | 启动失败、口吃 |
| 被错误定义、急于自证，或害怕被误解而试图校准 | 重复、重音 |
| 真相太残酷，突然理解后无法继续 | 沉默、失败吸气 |
| 想隐藏真正意图 | 说到一半改口、自我修正 |

不要只写「男人悲伤地结巴」，而要写**具体的失败过程**：

1. 嘴唇已经形成 “I” 的口型；
2. 声音却堵在喉中；
3. 一次浅而失败的吸气；
4. 尝试重新启动 “And I—”；
5. 再次停住。

困难应落在**最难面对的词**上：可能是 “I”“because”“but”，中文里的「你」「但是」「我」，或对方的名字。
不要平均分布在整句话上，否则容易变成喜剧式口吃。

### 五、悲伤的三股力量（约 03:21–04:16）

公式：**生理泄露 ＋ 自我控制 ＋ 关心目标。**

| 力量 | 案例中的可见表现 |
|---|---|
| 生理泄露 | 眼红、吞咽、气息失去控制——身体藏不住痛苦 |
| 自我控制 | 移开视线、压回哭腔、不让眼泪流下，努力维持没事的样子 |
| 关心目标 | 自己快崩溃，仍想保护、安慰对方 |

「男人悲伤欲绝，泪流满面地说」只写了结果，没有表演过程。
教程的改写包括：眼眶轻微泛红、像刚哭过但没有泪痕、短暂看向女人便移开、困难吞咽、句子在 “I” 处连续启动失败，以及**只有安慰女人时短暂恢复流畅**。
这些动作不是装饰，而是共同构成人物的心理证据。

作者强调：**高级的悲伤不是增加表情，而是让表情受到阻力。**
越痛苦，越努力表现得没事；两股力量同时在脸上，观众才看见人物正在承受什么。
这针对本案例的压抑悲伤，不代表所有戏都必须克制、不准哭，也不是每镜都要执行同一份微动作清单。

### 六、四层提示词分工（约 04:16–04:48）

作者在自己的平台上选模型、时长、画幅，先用风格库定影像风格，避免大量色调描述和表演指令争篇幅。示例没有垫图、垫视频，靠一段约 3,668 字符的长提示词。**这不能推论为提示词越长越好，或一次生成必定成功。**

| 层次 | 职责 |
|---|---|
| 全局设定 | 画幅、环境、光线、轴线、场景与人物连续性——先建立共同世界 |
| 人物内核 | 声线、潜台词、情绪方向，以及人物真正想完成的目标 |
| 时间轴 | 说话人、原句、触发词、动作、声音重叠和听者反应 |
| 声音与镜头 | 口型、方位、环境声、切镜连续，以及明确禁止的行为 |

教程点出的禁止行为：
- 不要轮流念稿；
- 不要自动补完已经被打断的句子；
- 不要把口吃演成机械重复。

四层的目的不是增加字数，而是**让信息各司其职、彼此校验**。

### 七、每小段编排公式（约 04:48–05:12）

教学画面给出的结构：

> **时间码 → 说话目标 → 原句＋触发词 → 可见反应 → 声音动作 → 话轮＋听者反应**

案例提示词还展示了动作连续性：右手抬起、悬停、失力下降是**一条动作线**，不反复摆动；切镜改变景别和观察对象，不应重置站位、朝向或双手动作阶段。

### 八、生成后审片：三项检查

1. **声音是否真正重叠？** 不是上一句被静音后，下一句才整齐出现。
2. **口吃是否发生在身体上？** 检查呼吸、口型、吞咽，而不只听重复字。
3. **切镜后情绪是否连续？** 眼部湿润程度、视线和动作不能一切镜就重置。

**修改原则：错误发生在哪一层，就只改对应层。** 不要同时重写风格、人物和台词，否则无法判断改动原因。

### 九、片尾结论（约 05:12–05:40）

AI 演员像人，不只是终于学会哭，而是能表现出**有些话无法说出口**。
好的对白提示词不是把每句台词写漂亮，而是安排双方同一秒如何靠近、碰撞，又退回沉默。
偶尔的失序可以带来真实感，但它必须属于人物和情境，不能变成随机噪声。

### 十、最容易上手的起手式

不要只写：

> 他很难过，他做了什么动作。

先想明白：

> 他想＿＿，但是＿＿；当对方说到 / 做出＿＿时，他转而＿＿。

套进教程案例：

> 他想解释自己，但是情绪使他说不完整；当女人认为自己在折磨他时，他转而先安慰她，因此短暂说顺了。

先把这条因果想明白，再选口型、呼吸、视线和声音重叠的具体写法。不是反过来先堆动作，也不是每段都套同一套表现。

## 第二部分：在 Toonflow 怎么用

### 优先级

用户已确认的剧本、对白与明确要求 > 本技能执行规则 > 本文 > 教程原示例。

涉及人物表演/对白时默认优先参考本文；非对白肢体表演取目标、触发、动作与变化的适用原则，纯环境不硬套。把源剧情或已确认设计支持的「目标/原因 → 触发 → 可见动作/声音 → 对方反应/状态变化」直接写入实际分镜和最终视频提示词的既有描述，不只内部分析或另写设计依据。简短自然连写，不给每个动作附心理段落，不新开字段或改变格式；无依据的环节不补，不编隐藏动机，不强加结巴、抢话、沉默或微动作。

### 最重要的一条：两个阶段用法不同

| 阶段 | 能做什么 |
|---|---|
| **写剧本 / 改编阶段**（剧本未定稿） | 可完整使用本文：设计目标、阻碍、触发，提出哪里结巴、哪里抢话、哪里沉默。写成剧本里的动作与停顿，标为「设计提案」交用户确认。确认后就成为源剧情。 |
| **Seedance 提示词阶段**（workflow 硬隔离） | 将源剧情或已确认设计**已有**的目标/原因与触发简短连入动作、声音和反应过程，写进最终提示词；已有停顿、打断、说不下去等用本文方法具体化。不能新增剧本没有的结巴、抢话、沉默、动机或小动作。 |

原因：workflow PART A 有剧情保真锁（A0.1），并规定不推断动机（A6.2）、微反应必须有源剧情依据（A6.4、A12.6）。

### 与 workflow（PART A）逐条对接

| 本文内容 | PART A 规则 | 怎么处理 |
|---|---|---|
| 目标 → 阻碍 → 触发 → 行为变化 | A6.2 只有原剧情能看出目标时才写 | 剧本里看得出的就写成可执行目标；看不出的不补 |
| 结巴、改口、失败吸气 | A3.2「剧本明确要求的停顿、结巴」另计时 | 剧本有才写，且写成具体过程（口型 → 堵住 → 吸气 → 重启） |
| 触发词驱动抢话 / 反应 | A6.7 反应须有明确触发词或触发动作 | 完全一致，可直接作为 A6.7 的写法 |
| 不平均分布困难、不堆微动作 | A6.8 克制型爆发、A6.9 微表情上限（0 个允许） | 一致 |
| 不补完被打断的句子 | A12.15 原文照抄、A3.2 不吞句尾 | 剧本用破折号等标出的断句保持断开，这就是「原文照抄」；没断开的完整句仍不得吞尾 |
| 声音重叠 0.1 / 0.2 秒 | A2.3、A3.2 时长预算 | 重叠部分可并行计时；不是配额，剧本没要求抢话就不重叠 |
| 四层分工 | A9.2.0 字段白名单（2.5） | **不新开字段**。全局设定 → `Objective` / `Immutable locks` / `Visual direction`；时间轴与话轮 → `Timeline`（台词嵌在动作发生处）；声音 → `Audio direction`；教程的三条禁止 → 按本段实际风险写进 `Avoid`；人物内核不单列，有依据的简短目标/原因与可见行为连写进 `Timeline` |
| 每小段编排公式 | A9.2.1 Timeline 用时间块 + 连续自然语言 | 有依据的目标/原因、触发、动作/声音和反应变化须落入实际正文，仍是一段自然语言，不拆成子标题 |
| 四层分工（H3） | A9.3 官方字段 | **不新开字段**，四层是设计职责，不替代 H3 字段：参考身份 → `subject_definitions`；任务 → `summary`；保留 → `retention_analysis`；表演因果、话轮与切点 → `integrated_multimodal_description` / `detailed_description`；环境与同期音 → `overall_soundscape`；H3 无 `Avoid`，教程的三条禁止改写为对应镜头的正向描述 |
| 切镜情绪 / 动作阶段连续 | A8 跨段连续性、A12.18.1 穿帮审计 | 一致，加作其中一项检查 |
| 三项审片检查 | `stateAndDelivery` 生成验收 | 可作为对白片段的验收要点；修改按「哪层错改哪层」回到 PART A 受影响项 |

### 与 v118workflow（knowledge）对接

- `scriptCraft` 情绪四通道（行动 / 语言：改口、停顿、节奏变化 / 环境 / 独白）和本文第四、五节一致；本文补充「按心理障碍选不流畅类型」。
- `narrativeGenres` 对白「表面话、真实目的、沉默由谁制造」与第二、三节一致。

- `storyboardTable` 的「画面描述」直接写有依据的简短原因、触发、动作及反应变化，声音沿用台词/音效列；不新增列。

## 第三部分：示例对照（从情绪标签到表演过程）

> 以下是整理者按教程方法改写的教学示例，三例分别解释目标变化、抢话与压抑悲伤，不是必须叠加使用的动作清单。
> 在 Seedance 阶段使用时，前提是剧本已经写了「他说不下去」「她被打断」「他忍着」等内容。

### 例子一：为什么只写「悲伤」不够？

**不够具体：只写情绪标签**

```text
男人非常悲伤，眼眶泛红，结结巴巴地说：“I’m not.”
女人心疼地看着他，说：“I don’t want to torture you.”
男人温柔地回答：“You’re not torturing me.”
```

模型知道要悲伤、要结巴，却不知道为什么卡住、卡在哪里，以及为什么下一句又能说顺。结果可能只是皱眉、重复几个字，然后照顺序念完。

**改写：明确他想做什么，但做不到什么**

```text
男人试图否认女人刚才对他的说法，但情绪使他无法把解释组织完整。
他说出“I’m not.”，试图继续，嘴唇已经准备发出下一个“I”，声音却没有出来；一次浅短的吸气后，再次停住。
女人看见他无法继续，不催促他，轻声说：“I don’t want to torture you.”
听到“torture you”，男人把注意力从自己的痛苦转向她。
他不想让她觉得自己正在伤害他，因此这次回答短暂恢复完整：“You’re not torturing me.”
说完后，他仍没有恢复平静。
```

区别不是「悲伤，所以结巴」，而是「解释自己时说不出，需要安慰她时说得出」。同一个人前后语言状态不同，因为目标变了。

### 例子二：怎样写抢话，才不是乱插嘴？

**不够具体：只要求效果**

```text
女人说话时，男人激动地打断她，两人声音重叠，情绪强烈。
```

这可能生成两个人同时喊，却听不出为什么抢。

**改写：指定触发词，以及打断后的双方反应**

```text
女人试图继续说：“You can’t just die—”
“die”一出口，男人立即抢入：“I’m not. I’m not.”，不等她把后面的话说完。
他的否认压到她尚未结束的尾音上。
女人的声音不是被瞬间切断，而是在听见他的否认后停下来，把话语权让给他。
男人急于否认，却无法继续解释；女人没有马上用下一句填满他的停顿。
```

因果链：听到 “die” → 无法接受这个说法 → 本能否认 → 她停下 → 他又说不下去。
不只是声音重叠，还要设计谁进入、谁退出，以及谁最终也没能说完。

### 例子三：「忍着悲伤」具体怎么写？

**不够具体：堆表情和动作**

```text
男人悲伤欲绝，眼红、低头、吞咽、嘴唇颤抖、握拳、流泪。
```

动作很多，却未必组成同一个心理过程。问题不在于这些动作不能用，而在于它们缺少共同的心理原因。

**改写：让动作体现互相拉扯的力量**

```text
男人不想让女人看见自己快要失控。
眼眶已经泛红，他短暂看向她，又移开视线，试图把声音压稳。
他准备继续解释，却在“I”处停住，吞咽后仍没能说下去。
但当女人开始责怪自己时，他重新看向她，努力把安慰她的那句话说完整。
他的语言暂时稳定下来，眼中的痛苦却没有消失。
```

| 教程中的力量 | 示例里对应什么 |
|---|---|
| 生理泄露：身体藏不住 | 眼红、声音卡住 |
| 自我控制：努力维持稳定 | 移开视线、试图压稳声音 |
| 关心目标：仍在保护对方 | 她自责时，努力把安慰说完整 |

不是给悲伤增加更多动作，而是让观众看见他正在努力不崩溃。

### 例子四：放进 Seedance 2.5 的 Timeline

**假设：** 剧本或已确认设计已明确男人无法接受女人的说法、试图否认并继续解释，女人的话被打断、男人否认后说不下去及下列反应；已有两人的参考图。仅在这些内容有依据时使用，不把示例移植为项目事实。

```text
【0:00-0:06】双人中景，女人在画面左，男人在画面右，两人身份与造型沿用参考图。女人说：“You can’t just die—”，“die”刚出口，男人因无法接受这个说法，立即接上：“I’m not. I’m not.”，他的声音压在她尚未结束的尾音上；她没有被瞬间切断，而是听见否认后停下，把话让给他。
【0:06-0:11】切男人近景。他想继续解释，嘴唇已形成“I”的口型，声音没出来，一次浅短吸气后再次停住，视线短暂移开；画外的女人没有马上开口填满这段停顿。
```

对应写法：
- 话轮（谁进入、谁退让）和触发词（“die”）都写在 `Timeline` 里，台词嵌在动作发生处；
- 被打断的句子保留原文的破折号，不补完；
- 失败启动写成身体过程，只出现在剧本写了「说不下去」的地方；
- `Audio direction` 可写「两人对白有短暂自然重叠，不做轮流念稿式的整齐衔接」；
- `Avoid` 按本段风险写一两项，如「补完被打断的句子、机械重复式口吃」。
